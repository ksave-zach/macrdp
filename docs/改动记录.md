# 改动记录

本仓库 fork 自 [x6nux/macrdp](https://github.com/x6nux/macrdp)。本文档记录本仓库相对原仓库（最后一次推送 2026-05-18）的全部改动。

## 未推送改动

按提交时间先后列出（旧 → 新）：

- **`4a2e6ee` add, bug fixed.** — 输入管线综合修复：键盘修饰键（Shift / Ctrl / Option / Cmd / CapsLock）状态跟踪、按键映射重写（Win → Command、Alt → Option）、鼠标相对模式处理、服务端与协议层输入处理器调整，构建脚本补充 Swift 运行库 rpath。
- **`bfb0df6` Fix, input login bug** — 修复锁屏 / 登录界面输入异常：新连接时发送 caffeinate 唤醒（让 loginwindow 重新加载键盘输入源，避免密码框打错字），事件源改用 HIDSystemState。
- **`8e406c9` Fix, mouse** — 鼠标修复：按压状态下移动改用对应 Dragged 事件（拖拽操作生效）；滚轮单位由 ±120 换算为行数。
- **`5538a4a` Add, default no audio** — 音频默认关闭。
- **`7536d06` Fix, double-click not working on remote desktop** — 修复双击失效：按 macOS 双击窗口（500ms / 5px）跟踪点击状态并设置 clickCount。
- **`6ce0165` Fix, mouse offset** — 修复鼠标位置偏移：坐标映射基准改为每秒实时读取显示器尺寸，不再使用启动时快照（原 2560×1440 快照与实际的 1920×1080 不符，导致约 ×1.333 过缩放）。
- **`64916fb` Add, GFX backpressure** — 新增 GFX 背压控制：未确认帧积压 ≥20 时跳过编码与发送，回落 ≤6 时恢复并强制关键帧（IDR），另设 10 秒看门狗复位；含 3 个单元测试。

## 2026-10-11 隐私审计修复

- **认证失败日志移除密码明文输出**（`crates/ironrdp-acceptor-patched/src/connection.rs`）— 原代码在凭据不匹配时会把客户端提交的密码与服务端配置的密码以明文字节写入日志；现只保留长度信息，不再输出任何密码内容。
- **About 页 GitHub 链接修正**（`macrdp-ui/src/pages/About.tsx`）— 原链接指向 `github.com/aspect-build/macrdp`（404 死链），改为本仓库 `github.com/ksave-zach/macrdp`。
- **文档中文化** — 移除 `README_EN.md`；`config.example.toml` 改为中文注释版（删除内容重复的 `config.zh.example.toml`）；新增本文档。
